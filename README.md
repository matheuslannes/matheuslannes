## 🛡️ About Me

I'm a **Cybersecurity Analyst** passionate about:

- 🛡️ Vulnerability assessment and threat mitigation  
- 📊 Security monitoring and incident response  
- 🧠 Continuous learning in offensive and defensive security
- 🔍 Penetration testing in controlled environments for proactive security flaw assessment
- ⚙️ Automation of security tasks using scripts and tools like Python, Bash, or PowerShell
- 🧩 Integration of security solutions with SIEM and EDR platforms
- 🗂️ Documentation and development of playbooks for incident response and system hardening
- 🛠️ Vulnerability management using tools such as Qualys or OpenVAS
- 🔐 Log analysis and event correlation for detection of suspicious activities
- 🔄 Participation in attack simulations (Red vs Blue Team)
- 💬 Collaboration with infrastructure and development teams to implement security from the ground up
